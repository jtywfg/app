# Android document scanning (1.2.0)

The home screen's NEW scan entry opens smart single/batch capture and book single/double capture. Book single/double modes can switch during a session. Double-page captures append two separately editable pages: top/bottom with initial counterclockwise rotation, or left/right. Page rotation can be corrected in the editor.

The sampled camera preview and still-image processing share the bundled OpenCV detector. Multiple edge/brightness thresholds find convex document contours. Still images are perspective-corrected; uncertain detections retain the full region and explicitly ask for manual correction. Four corners and four edges can be dragged with a magnifier. Bounds and convexity are validated before processing. Edits always render from the original normalized photo. This performs planar perspective correction, not curved-book reconstruction or generative restoration.

Rotate, crop, retake, delete and reorder pages, apply grayscale/black-and-white/shadow correction, and select pages for export. Export supports image-based multi-page PDF, a real DOCX with locally recognized editable Chinese/English text plus the original scans, one long JPEG, and individual gallery images. Text and complex table layouts require review. Recognition is bundled in the APK and needs no model download; no photos or recognized text are uploaded.

`modules/document-scanner` is an Expo local Android module (OpenCV 4.12.0, bundled ML Kit Chinese text recognition 16.0.1). It requires a new native APK and does not run in Expo Go or old APKs. iOS has no native scanner module yet, and displays an installation message. On Android 10+, PDF, DOCX and long JPEG exports are written to public `Download/PinPic` through MediaStore. Pending writes become visible only after completion; failed writes are removed. Export success no longer depends on a share sheet. Individual gallery saving still uses the PinPic album.

The preview grid fits two complete rows to the available screen height. Checkboxes select pages for batch move/delete/export; long-pressing a photo drags it to another position, with edge scrolling for longer documents. The editor keeps filters next to crop/rotate/retake and reserves the remaining space for the image. Captured thumbnails sit above the camera's confirm button rather than covering its viewfinder.

Sessions support up to 50 pages. Long images are capped at 28,000 pixels high and 16 megapixels; too many pages should be exported as PDF. Processing files are in app cache; successful Android exports remain in public Downloads after their generated cache files are removed. Page lists stay in memory across camera/edit/preview transitions; persistent drafts across app termination are not implemented. Exit prompts users to export/save first. Live detection temp captures are deleted after analysis.

Validation: `npm run typecheck`, `npm run lint`, `node --test tests/*.test.cjs`, Android Metro export, Android autolinking, then EAS preview APK compilation. Automated geometry tests cover double-page boundaries/order, edge movement, corner constraints, invalid quadrilaterals, and display-to-source coordinate mapping. Real-device checks should cover low-contrast paper, cluttered backgrounds, curved books, repeated capture, manual crop, Chinese/English Word output, PDF page order, long images and gallery saving.
